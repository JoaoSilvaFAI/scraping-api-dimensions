# Dimensions AI

## 1. Dimensions Metrics API (Gratuita para Pesquisadores)

Se o seu objetivo é apenas coletar métricas de citações e indicadores de publicações para fins não comerciais (como sua própria pesquisa acadêmica ou ensino), você pode usar a [Dimensions Metrics API](https://www.dimensions.ai/products/all-products/metrics-api/) sem custos.

- O que oferece: Acesso programático a indicadores de nível de artigo e citações.
- Como solicitar: Você deve preencher um formulário de [solicitação de acesso](https://www.dimensions.ai/request-access/) descrevendo seu caso de uso. [4, 5]

## 2. Dimensions Analytics API (Paga ou Institucional)

Esta é a API completa que permite buscas complexas usando a linguagem DSL (Dimensions Search Language).

- Acesso: Geralmente é restrito a assinantes da versão Dimensions Analytics.
- UFSM: Atualmente, o acesso institucional da UFSM foca no SciVal. No entanto, se você for um pesquisador em bibliometria ou cientometria, pode tentar solicitar acesso gratuito temporário para projetos específicos através do programa de [Open Research](https://www.dimensions.ai/products/open-research/) da plataforma.

## Uso Básico da API do Dimensions

 1. Instalação: pip install dimcli
 2. Login: Você precisará de uma API Key gerada na seção "My Account" do portal Dimensions.
 3. Consulta: As buscas seguem um padrão simples: search publications for "termo" return publications.
